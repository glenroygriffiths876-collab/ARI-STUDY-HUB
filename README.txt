ARIANA'S PURPLE STUDY HUB — GITHUB PAGES PACKAGE v11

UPLOAD:
1. Extract this ZIP.
2. Upload ALL extracted files/folders into the SAME GitHub Pages folder where the old Study Hub files are located.
3. Choose Replace/Overwrite for the old index.html, manifest.webmanifest, sw.js and icons folder.
4. Keep the folder structure exactly as shown:

   index.html
   manifest.webmanifest
   sw.js
   .nojekyll
   icons/
      icon-192.png
      icon-512.png
      icon-maskable-512.png

5. After GitHub Pages redeploys, open the site and refresh once. If an older installed PWA is heavily cached, close/reopen it or clear the site cache once.

The paths are relative, so no repository-specific edits are required.
