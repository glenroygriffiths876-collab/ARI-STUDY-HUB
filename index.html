How Mimi helps

➗Math: calculate, show each step, then check the answer.
📚English: find the instruction word, use evidence, then build the answer.
🔬Science: identify the idea, evidence/variables, then explain cause and effect.
🌍Social/History/Geography: point → explain → Jamaican/Caribbean example.
🇫🇷Languages: meaning → grammar pattern → short example → pronunciation cue where useful.
🎨Practical/creative subjects: key term → what to do → example → how to improve.

The Hub works as a normal study app when index.html is opened directly. Full Chrome installation, service-worker caching and closed-app background features require HTTPS or localhost. About the curriculum

Verified Grade 8 Jamaican curriculum content is built into each subject. French, Geography and History include complete Grade 8 study content, but where a current public Ministry Grade 8 term-by-term sequence was not verified, the Hub labels the sequence for school confirmation instead of presenting it as an official Holy Childhood sequence.
